# Marketing Analytics Dashboard

## 📌 Project Overview
This project is an interactive dashboard designed to analyze and visualize marketing campaign performance across multiple platforms, including Google Ads, Meta Ads, and TikTok Ads.

The goal of the project is to support **data-driven decision-making** by providing a clear overview of key performance indicators (KPIs) for digital marketing campaigns.

---

## 🧠 Problem Context
Marketing teams often work with fragmented data from multiple advertising platforms, making it difficult to gain a holistic view of campaign performance.

This dashboard addresses that challenge by:
- Aggregating data from multiple sources
- Standardizing metrics across platforms
- Presenting insights in an accessible and actionable format

---

## ⚙️ System Design
The system is structured as follows:
- Data sources: Google Ads, Meta Ads, TikTok Ads (mock data)
- Backend logic: Python-based data processing
- Visualization: Interactive dashboard interface

Mock data is used to simulate real campaign data and focus on system design and analytics logic.

---

## 📊 Key Features
- Cross-platform campaign comparison
- KPI tracking (e.g. impressions, clicks, conversions)
- Modular data source design
- Scalable structure for adding new platforms

---

## 🛠️ Technologies Used
- Python
- Data processing libraries
- Dashboard framework (Python-based)
- Mock data for simulation
